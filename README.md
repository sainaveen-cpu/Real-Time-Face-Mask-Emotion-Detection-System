# Emotion Detection System

A computer vision project that detects faces from a live webcam feed or an uploaded image and classifies each person's emotion (happy, sad, angry, neutral, and more) using a Convolutional Neural Network trained on the FER-2013 dataset.

Each detected face is labeled with the predicted emotion and a confidence score. The app also tracks how emotions change over a session and shows them in a simple history chart.

## Features
- Live webcam emotion detection
- Image upload support
- Confidence score for each prediction
- Emotion history chart

## Tech Stack
Python, OpenCV, TensorFlow/Keras, Streamlit

## Dataset
FER-2013 (Kaggle)
